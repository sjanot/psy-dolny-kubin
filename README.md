# Psy v Dolnom Kubíne 🐕

Nezávislý informačný prehľad o psoch v Dolnom Kubíne — počet psov, daň za psa, história psích výbehov a moderné eko riešenia psích záchodov. Vytvorené z verejne dostupných dokumentov mesta.

**Živá stránka:** https://sjanot.github.io/psy-dolny-kubin/

## Obsah
- Počet prihlásených psov a výnos dane za psa (2020–2024)
- Sadzby dane za psa podľa typu bývania
- Vyhradené plochy pre venčenie (VZN č. 3/2009, novela 9/2013)
- Eko riešenia: ECO DOG toilet a klasické pieskové psie záchody

## Zdroje
- Záverečný účet mesta Dolný Kubín za rok 2024
- Kronika mesta Dolný Kubín 2008
- VZN č. 3/2009 v znení 9/2013 o držaní a vodení psov
